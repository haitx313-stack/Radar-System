RADAR SYSTEM – Arduino Radar System

Overview

This project is a Radar like detecting system using Arduino, sensors, and servo.

Features

- Detect a wide angle area of 270 degrees.
- Ultrasonic sensor detecs objects.
- Using servo sg-90 with smooth movememt.
- Object detection shows on screen via using processing softwar with that's code logic.

Components Used

- Arduino Uno / Nano
- Ultrasonic Sensor
- Servo sg-90
- Jumper wires

How to Use

1. Upload code to Arduino from Arduino IDE and to processing 4
2. Run processing 4 - see animation on screen
3. place object front of ultrasonic sensor and you can see RED Detection Area
